# jupyter-exploration

This repository contains my first Jupyter notebook for ITAI 2373 Natural Language Processing, Module 1. It introduces Markdown cells, Python code cells, the notebook kernel, and simple program output.

## Contents
- `My_First_Notebook.ipynb` — example Markdown and executable Python cells.

## How to open
Open the `.ipynb` file in Google Colab, Jupyter Notebook, JupyterLab, or Visual Studio Code with the Jupyter extension. Run the cells in order.
